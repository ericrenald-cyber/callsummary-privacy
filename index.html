Politique de confidentialité

Dernière mise à jour : 5 mai 2026

En résumé : Vos données restent sur votre téléphone. Nous ne vendons, ne partageons et ne monétisons aucune donnée personnelle.

1. Qui sommes-nous

Je L'Notes (ci-après « l'Application ») est une application mobile de transcription et de résumé automatique d'appels téléphoniques, développée par un développeur indépendant.

2. Données collectées

L'Application peut collecter et traiter les données suivantes :

  • Informations de compte : nom, adresse email, mot de passe (chiffré)
  • Contacts : nom, numéro de téléphone, email, entreprise (uniquement les contacts que vous ajoutez manuellement ou importez)
  • Enregistrements audio : les appels que vous choisissez d'enregistrer
  • Transcriptions et résumés : générés par le service d'IA que vous configurez
  • Métadonnées d'appels : date, durée, direction (entrant/sortant)

3. Stockage des données

Toutes vos données sont stockées localement sur votre appareil (base de données SQLite). La sauvegarde vers un serveur est optionnelle et sous votre contrôle.
  • Stockage local : base de données SQLite sur votre téléphone
  • Sauvegarde serveur : si activée, vos données sont envoyées vers votre serveur personnel de manière chiffrée (HTTPS)
  • Clé API : stockée de manière sécurisée via le trousseau de votre appareil (Secure Store)

4. Services tiers d'intelligence artificielle

Pour générer la transcription et le résumé d'un appel, l'Application doit envoyer le fichier audio à un service d'IA tiers. Aucune transcription n'est effectuée localement : l'envoi à un service tiers est techniquement nécessaire.

Fournisseurs IA disponibles (au choix exclusif de l'utilisateur) :

  • Anthropic (Claude) — politique de confidentialité
  • OpenAI (ChatGPT, Copilot) — politique de confidentialité
  • Google (Gemini) — politique de confidentialité
  • Microsoft (Copilot via OpenAI) — politique de confidentialité

Données exactes envoyées au fournisseur IA :

  • Le fichier audio (.wav) que vous choisissez de transcrire
  • La transcription générée (renvoyée au fournisseur lors de l'étape de résumé)

Aucun contact, aucun nom, aucun numéro de téléphone, aucune métadonnée d'appel et aucune information de compte ne sont transmis aux fournisseurs IA.

Comment les données sont envoyées : directement depuis votre appareil vers l'API du fournisseur via une connexion HTTPS chiffrée, en utilisant votre clé API personnelle que vous configurez dans l'Application. Nous (le développeur de Je L'Notes) n'intermédiatons jamais ces requêtes et n'avons aucun accès à vos audios, transcriptions ou résumés.

Consentement explicite avant tout envoi : avant qu'aucune donnée ne soit envoyée à un service IA, l'Application affiche un écran de consentement (Réglages > Clé API) qui détaille (i) quelles données seront envoyées, (ii) à quel fournisseur, et (iii) comment retirer le consentement. Tant que vous n'avez pas accepté ce consentement, l'Application refuse toute transcription. Vous pouvez retirer votre consentement à tout moment en supprimant votre clé API dans les Réglages.

Protection équivalente offerte par les tiers

Nous avons sélectionné ces fournisseurs parce qu'ils offrent des garanties de protection des données au moins équivalentes à celles de la présente politique :

  • Conformité réglementaire : Anthropic, OpenAI, Google et Microsoft déclarent leur conformité au RGPD (UE) et au CCPA (Californie), avec des Data Processing Agreements (DPA) standards.
  • Certifications de sécurité : les quatre fournisseurs sont certifiés SOC 2 Type II ; chiffrement des données en transit (TLS) et au repos.
  • Pas d'entraînement sur vos données par défaut : par leurs conditions API actuelles, Anthropic, OpenAI, Google (Gemini API tier payant) et Microsoft n'utilisent pas les données soumises via API pour entraîner leurs modèles.
  • Rétention limitée : les fournisseurs limitent la rétention des contenus API (typiquement 30 jours pour la détection d'abus, puis suppression), conformément à leurs politiques publiées.

Nous vous invitons à consulter la politique du fournisseur que vous choisissez (liens ci-dessus) pour les détails à jour. Si un fournisseur cessait d'offrir une protection équivalente, nous le retirerions de l'Application.

5. Permissions requises

  • Microphone : pour enregistrer les appels
  • État des appels : pour détecter automatiquement les appels entrants et sortants
  • Contacts : uniquement si vous choisissez d'importer vos contacts

6. Partage de données

Nous ne partageons, vendons ou louons aucune donnée personnelle à des tiers. Vos données ne sont jamais utilisées à des fins publicitaires.

7. Sécurité

  • Mots de passe chiffrés (bcrypt)
  • Authentification par jeton JWT
  • Clés API stockées dans le trousseau sécurisé de l'appareil
  • Communications serveur en HTTPS

8. Vos droits

Conformément au RGPD, vous pouvez à tout moment :

  • Accéder à toutes vos données (elles sont sur votre téléphone)
  • Supprimer vos données en désinstallant l'application
  • Exporter vos données via la fonction de sauvegarde
  • Vous déconnecter et supprimer votre compte serveur

9. Mineurs

L'Application n'est pas destinée aux personnes de moins de 16 ans.

10. Modifications

Nous nous réservons le droit de modifier cette politique. Toute modification sera indiquée par une mise à jour de la date en haut de cette page.
